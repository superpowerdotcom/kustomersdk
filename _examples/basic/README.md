# Basic Kustomer SDK Example

This example demonstrates how to use the Kustomer SDK to send SMS and Email messages.

## Running the Example

1. Run the example:

`doppler run -p go-kustomersdk -c dev -- go run main.go`

## What This Example Does

This example performs the following operations:

1. Initializes the Kustomer SDK client with your API key
2. Sends an SMS message to a customer
3. Sends an HTML email to a customer

You can modify the code to test different message formats, chunking of longer messages, and other SDK functionality.
